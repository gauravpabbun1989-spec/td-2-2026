# TicketDepart organic traffic growth plan

## Goal

Increase qualified U.S. organic search traffic and convert that traffic into phone calls. Google Ads is intentionally excluded.

## Evidence from current search landscape

Current search results show independent flight-booking services competing around:
- book a flight by phone
- international flight booking by phone
- last-minute flight booking
- group flight booking
- airline-specific booking assistance
- destination and trip-type pages

The opportunity is not to copy those sites. TicketDepart should publish useful pages only where the page represents a real service or a genuinely useful travel answer.

## Priority work

### 1. Protect and strengthen the existing money pages

Primary:
- /book-a-flight-by-phone
- /flight-booking
- /flight-booking-assistance
- /international-flight-booking
- /last-minute-flight-booking
- /same-day-flight-booking
- /multi-city-flight-booking
- /group-flight-booking

Keep a prominent phone CTA, clear independent-agency disclosure, useful FAQs, and strong internal links.

### 2. Build only high-value supporting topics

Potential next topics should be validated against Search Console demand before publication:
- business class flight booking assistance
- family flight booking assistance
- flight change and rebooking assistance
- canceled-flight rebooking help
- complex international itinerary planning
- airport/date flexibility for urgent travel

Do not mass-produce city/airport pages just to capture keywords.

### 3. Use Search Console as the demand loop

Review queries, pages, countries, devices, impressions, clicks and CTR. Prioritize:
- high-impression / low-CTR pages for title and snippet improvements;
- queries where TicketDepart already receives impressions but has weak clicks;
- pages ranking around the second page where useful content improvements can improve relevance;
- pages generating phone clicks in GA4.

Google documents these workflows in Search Console's Performance report guidance.

### 4. Use external SEO audits, not repository integrations

When a technical crawl is needed, run the SEO crawler separately from this website repository. Do not commit the crawler, its workflow, credentials, business profile, generated reports or tool-specific configuration into the production project.

### 5. Build authority carefully

Use relevant, legitimate travel/business profiles and editorial opportunities. Do not buy spam links, automate forum posting, fabricate reviews, or create pages whose only purpose is to funnel search traffic.

### 6. Conversion loop

For every organic landing page:
Google result -> landing page -> clear phone CTA -> phone click -> call -> booking.

GA4's `phone_click` event measures the website-side conversion. It should be analyzed by landing page and first-touch attribution.

## Guardrails

Google's spam policies explicitly warn against doorway abuse and scaled content abuse. Therefore this project will not use:
- hundreds of near-identical city/airport pages;
- AI-generated pages with little unique value;
- keyword stuffing;
- fake reviews or testimonials;
- fake airline affiliation;
- invented prices, availability, credentials, partnerships, or guarantees.

## Review cadence

1. Run an external/local SEO audit when needed.
2. Review Search Console and GA4.
3. Fix technical blockers.
4. Improve pages with demonstrated demand.
5. Add only validated supporting content.
6. Measure phone-click changes.
7. Repeat.
